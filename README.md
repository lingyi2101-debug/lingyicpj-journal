# CPJ — A Curious Designer's Journal

A playful, responsive Creative Process Journal rebuilt from the original Framer site.

- **Home:** colourful CPJ cover, ski illustration, quick access to the three DSF questions
- **Contents:** About Me, Course Review, Design Research & Fieldwork, Self Reflection
- **Weekly journal:** Weeks 01–13 with original English writing, photos and page navigation
- **Interactions:** Tap-to-switch photo collections and gallery views
- **External project:** [Wello](https://lingyi2101-debug.github.io/wello-reach/)

Original Framer project remains unchanged. This repository is a standalone website for deployment to Vercel or GitHub Pages.

## Development

This is a static HTML/CSS/JavaScript site. Open `index.html` locally, or deploy the repository root on Vercel with framework set to **Other** and no build command.
